# SekiMod Assistant v0.3

Windows 10/11 x64。C++17 / Win32 原生版，支持简体中文、英文、日文，不需要安装 .NET 或 Visual C++ 运行库。主程序静态链接，使用 Windows 自带系统 DLL。下载模组时调用 Edge；界面自身不依赖浏览器。旧版 .NET 发行包保持独立。

## 启动

- 免安装版：完整解压 `SekiModAssistant-v0.3-Native-portable.zip`，双击 `SekiModAssistant.exe`。请保持 assets、tools、licenses 和配置文件完整，不能只复制主程序 EXE。
- 便携版及安装后的主程序启动时都会请求管理员权限。请在 Windows UAC 提示中同意；取消则不启动。程序启动后无需为获取管理员权限再次打开。
- 本地模组的大路径列表支持直接拖入多个文件、文件夹及压缩包，也可使用下方添加按钮；重复路径只添加一次。拖入仅加入待导入列表，点击“检查并导入到 mods”并确认后才安装。已配置普通资源管理器向管理员窗口发送文件拖放消息的兼容处理。
- 安装版：运行 `SekiModAssistant-v0.3-Native-Setup.exe`，为当前 Windows 用户安装到 %LOCALAPPDATA%/Programs/SekiModAssistantNative，提供独立卸载项，不替换 .NET 版。
- 使用安装器“浏览…”选择文件夹时，该文件夹作为安装父目录；软件自动安装到其下新建的 `SekiMod Assistant` 子文件夹。例如选择 `D:\Games`，最终路径为 `D:\Games\SekiMod Assistant`，安装界面会显示此最终路径。已有本工具安装可覆盖升级，若同名子文件夹含其他内容则停止，避免覆盖无关文件。
- 软件主页检测 Steam 与常见游戏位置，找不到时选择 `sekiro.exe`。找到并锁定有效游戏根目录后，自动建立缺失的空 mods 文件夹；若建立失败会明确提示。已有内容不受此步骤影响；安装前请退出游戏。
- 顶部提供“主页／在线预设／快速入门”三个页面。“在线预设”显示七个预设的下载与一键安装；“快速入门”独立显示完整指南和视频入口。


## v0.3 界面与升级

- 只更新 C++ 原生版；沿用 v0.2 的设置、下载记录、指纹和游戏备份。安装目标和卸载项保持 SekiModAssistantNative，支持覆盖升级。旧版发行包单独保留。
- 正文16像素、普通按钮18像素、导航22像素加粗（100% 缩放）；Per Monitor V2 跟随系统缩放，小屏内容允许滚动。
- 三页圆角墨蓝导航、白色文字、选中高亮；游戏目录上方显示“寻找并锁定游戏根目录”。内容区移除重复的软件名称。
- 图片背景按比例完整显示，空余区域为黑色，内容叠加半透明深色衬底；刀形多尺寸图标嵌入主程序、安装器和卸载器，快捷方式引用主程序图标。
- “语言选项”按钮展开中文、English、日本語菜单，切换立即生效并保存。
- 自定义窗口按钮采用用户提供的两张圆形素材，叠加最小化、最大化/还原和关闭符号；提供悬停提示。支持拖动、双击最大化/还原、边缘缩放、系统快捷键。最大化返回 HTMAXBUTTON 命中供系统贴靠识别；Win11 的悬停贴靠面板未在独立实机验证，不能保证所有系统版本都展示该面板。
- 安装器和普通弹窗使用自定义关闭按钮；是/否居中；文件选择器保留 Windows 样式。
## 小白手动安装mod快速指南：

（1）建议第一次玩流程类模组的新手小白用户使用预设功能下载并安装流程mod预设包。如果玩家想手工添加各种mod，请参考链接视频：
https://v.douyin.com/wmk_GI6325k/

（2）外观类mod
在游戏根目录中找到mods文件夹（若无可自己建立一个）→ 确保两个游戏引擎文件 dinput8.dll 和 modengine.ini 都在游戏根目录内 → 在mods文件夹中建立parts文件夹 → 在其中导入您的各种外观文件即可。
若外观模组还附带其他目录，请以该模组自身说明为准。

（3）流程类mod
在游戏根目录中找到mods文件夹（找到并锁定有效游戏根目录后，软件会自动建立缺失的mods文件夹；也可自行建立）→ 确保两个游戏引擎文件都在游戏根目录内 → 将您的所有mod资源文件夹（如action、chr、param、script、map、parts、menu等）导入到mods文件夹中即可。

（4）建议不要随意将某些mod一起混用，否则会有bug，导致游戏内不可预知的问题。

（5）其他说明
v0.3本地导入默认在已有mod基础上补充文件、覆盖同路径文件，其他文件保留；切换流程预设仍会确认后整体替换，避免不同流程模组混用。两种操作都会先备份。

在线预设支持自动解压、校验并安装。网盘分享页可能需要先在浏览器登录或输入提取码，下载后点击“一键安装”，必要时选择已下载的压缩包。

上移／下移说明
它们调整本次导入列表的处理顺序。软件从上到下合并文件；如果两个模组包含相同路径的文件，排在下面的文件会覆盖上面的文件；没有相同路径时，顺序通常不影响结果。它不是游戏运行时的加载顺序。

## v0.3 本地导入与状态

- 本地导入改为**增量合并**：补充新文件，覆盖同路径文件，保留其他旧文件，不再先清空整个mods。
- 拖入文件夹、资源目录或 ZIP/RAR/7Z/TAR/GZ/BZ2/XZ 等压缩包，检查预览后安装。同批文件可调整覆盖顺序，预览也列出将覆盖的现有文件。
- 每约3秒重新检查所选游戏的实际mods文件；也可手动刷新。首次识别大型预设需要计算哈希，可能耗时，后续复用未变化文件的校验缓存。
- 没有文件（包括只有空目录）显示红色“否”。存在文件显示绿色“是”。全部预设文件路径、大小及 SHA-256 匹配时显示预设名称，允许额外添加外观等文件；部分匹配显示“预设不完整或已修改”；没有任何预设路径交集时显示“未知mod”。不再仅靠旧安装记录猜测模组名称。
- “一键清除所有已安装mod”会弹出是/否确认。是：先备份，再清空所选游戏mods内部所有内容，保留mods文件夹及引擎；否：返回主页，不删除。可通过恢复按钮撤销。

## 在线预设：Edge下载、自动解压

本版提供七个预设：影武2.172、破晓V81-1.0、复兴1.16.1、不朽1.05.3、诡影V4.9、极道2.3、苇梁（版本未注明）。芦苇之国暂时移除，不与苇梁混同。软件不附带大型预设数据，也没有预设包文件夹选择功能。

1. 在第二页点击所需预设的“下载”，确认后固定打开Edge访问你提供的GitHub Releases直链。没有Edge时，询问是否使用默认浏览器。不同意即返回。
2. 下载由浏览器负责。软件不会将“打开链接”误报为“下载成功”，也不能保证GitHub链接可访问。请在Edge中确认下载完成。
3. 软件优先查找可读取的Edge各配置档下载目录和Windows“下载”已知文件夹。实际保存位置可能由用户修改或每次另选；界面显示的是候选位置，不保证一定在C盘。
4. 下载完成后点击“一键安装”，无需手动解压。软件会查找对应文件名、`(1)`/`(2)`副本及同名解压目录；多份候选由用户选择，找不到则允许手动选择压缩包。`.crdownload`临时文件不会被选为完整包，解压期间会保持只读锁并验证实际可完整读取。
5. 自动解压后定位资源目录；多套候选需要选择。已有内置文件指纹的预设逐文件校验，再显示安装预览。安装流程预设仍先备份并整体替换mods；本地导入继续增量合并。
6. 新增的不朽、诡影、极道、苇梁由于当前构建环境网络审批失败，尚无独立预先生成的文件指纹。首次安装会明确提示并要求确认文件来自指定链接，只检查压缩包完整解压与资源目录结构，不声称已独立验证版本身份；成功安装后记录实际安装文件指纹，之后用于校验与状态识别。未通过本工具安装前，这四个预设的手工安装内容可能只能显示未知或其他预设的部分匹配。
7. 断网时下载按钮禁用，红字显示“您目前无网络连接，无法使用在线下载功能。”本地导入、恢复和已下载的预设安装仍可使用。系统联网不代表GitHub站点可访问。

## 备份与限制

备份位于游戏根目录 `.sma-backup`，保留最近一次完整状态，包括旧引擎、mods及原本缺失的状态。恢复前保存当前状态，可再次恢复以撤销。连续操作会推进最近一次备份，不永久保留最初原版。中断操作下次会要求恢复。卸载软件不删除游戏中的mods、引擎或备份。

包内程序不执行；越界路径、绝对路径及链接会被拦截；引擎由配套文件统一提供。软件不修改、管理或备份游戏存档。破晓附带说明不建议使用旧存档。

原生版通过 55 项自测，涵盖本地合并与回滚、状态识别、清空与恢复、事务中断恢复、ZIP/7Z/TAR/GZIP/BZIP2/XZ、RAR 存储格式样本、密码与分卷归档、越界路径及符号链接拦截。另已验证 .NET 与原生版双向恢复备份、中文文件名、三语界面与小窗口布局。RAR 测试样本不代表穷尽所有 RAR 版本或密码组合。

七个链接已接入，但真实网络下载受构建环境网络审批限制尚未验证；新增四个真实预设包未核验。未启动真实游戏，未在独立 Windows 10/11 机器覆盖测试高 DPI、UAC、系统注册表安装卸载。安装程序文件部署、快捷方式和升级回滚使用隔离目录测试，模拟注册表写入，不声称完成真实用户环境安装卸载验证。

第三方许可证见软件 `tools` 与 `licenses`。Mod Engine与预设仍属于原作者。源码单独提供。
